# 能力检查表

## 统计与建模

- [ ] 能从原始数据写出研究的独立观测单位。
- [ ] 能区分模型、估计方法、推断方法、统计量和错误控制。
- [ ] 能解释 t = estimate / SE 的含义。
- [ ] 能解释 F 检验为什么适合联合检验一组系数。
- [ ] 能从 design matrix 解释 contrast。
- [ ] 能解释 repeated measures 为什么不能当作独立样本。
- [ ] 能判断何时需要 LME / GAMM。
- [ ] 能解释 FWE 与 FDR 控制目标的差别。
- [ ] 能设计合法的 permutation / exchangeability scheme。
- [ ] 能识别 feature selection / PCA / harmonization 的 data leakage。
- [ ] 能解释 ROC-AUC 与 PR-AUC 的差异。

## MRI

- [ ] 能解释 voxel size、affine、scanner/native/template space。
- [ ] 能解释 registration、normalization、resampling 的差别。
- [ ] 能解释 GMV/VBM 的计算链条以及 modulation。
- [ ] 能解释 BOLD 信号的生理来源。
- [ ] 能解释 first-level 与 group-level GLM。
- [ ] 能解释 diffusion weighting、b-value、b-vector、FA/MD。
- [ ] 能解释 tractography 不等同于真实轴突计数。

## EEG/MEG

- [ ] 能解释 reference 为什么改变所有 EEG 通道。
- [ ] 能解释 Nyquist、aliasing 和滤波相位。
- [ ] 能解释 ERP averaging 为什么提高信噪比。
- [ ] 能解释 ICA 的混合模型及其边界。
- [ ] 能解释时频分析的时间-频率分辨率权衡。
- [ ] 能解释 source localization 是病态 inverse problem。
- [ ] 能解释 volume conduction / field spread 对 connectivity 的影响。

## 脑刺激

- [ ] 能从 Maxwell/电场概念解释 TMS 与 tES 的物理差异。
- [ ] 能解释 MEP/RMT/AMT、SICI/ICF 的基本含义。
- [ ] 能解释 tDCS/tACS/tRNS 的刺激变量。
- [ ] 能区分设备电流/光功率与真正脑内剂量。
- [ ] 能解释 tPBM 的 irradiance 与 fluence。
- [ ] 能说明 sham/blinding 和剂量反应为什么是方法学核心。

## 脑网络

- [ ] 能从 time series 构造 functional connectivity。
- [ ] 能说明 Pearson correlation 不等于直接神经连接或因果。
- [ ] 能解释 degree/strength、clustering、path length、efficiency、modularity。
- [ ] 能说明 threshold/density 改变图指标。
- [ ] 能解释 NBS 显著是 component-level evidence。
- [ ] 能区分 subject permutation 与 graph null rewiring。
- [ ] 能说明空间自相关为什么需要 spin/Moran/BrainSMASH 一类 null。

## 论文阅读

- [ ] 能先找研究问题，而不是先看 p 值。
- [ ] 能分清 primary analysis 与 robustness analysis。
- [ ] 能指出结果的 inferential unit。
- [ ] 能区分 association、prediction 和 causality。
- [ ] 能把论文方法迁移到自己的设计，同时明确哪些只是推论。
