# 学习路线 V1

## Phase 1：把“统计语言”补齐

优先掌握：

- β、SE、t、F、χ²、df、CI、effect size
- correlation / partial correlation
- OLS / general linear model
- ANOVA/ANCOVA 与回归的统一关系
- generalized GLM
- LME/GLMM
- GAM/GAMM
- FWE/FDR
- permutation / TFCE / NBS
- cross-validation、nested CV、data leakage

目标：看到论文统计方法时，能说清 **模型、检验、统计量、自由度、多重比较和推断单位** 分别是什么。

## Phase 2：MRI 和脑网络主干

1. MRI/NIfTI/BIDS/空间坐标
2. registration / interpolation / resampling
3. structural MRI → segmentation / VBM / FreeSurfer
4. fMRI → BOLD、preprocessing、GLM、FC
5. dMRI → diffusion physics、tensor、FA/MD、tractography
6. connectome construction
7. graph theory / NBS / network control
8. individualized functional networks

目标：不依赖“软件按钮记忆”，能从数据生成机制解释分析流程。

## Phase 3：EEG / MEG

1. 采集物理与 reference
2. 采样、滤波和伪迹
3. ERP/ERF
4. time-frequency
5. ICA/SSP/SSS
6. forward/inverse problem
7. source localization / beamformer
8. connectivity / phase synchronization
9. cluster permutation / multiple comparisons

## Phase 4：脑刺激

### TMS
- induced electric field
- motor threshold / MEP
- paired-pulse physiology
- rTMS / TBS
- TMS-EEG
- neuronavigation / E-field

### tES
- current flow / montage
- tDCS / tACS / tRNS
- phase/frequency concepts
- impedance
- E-field modeling
- sham and blinding

### tPBM
- wavelength / irradiance / fluence
- tissue optics
- CW vs pulsed
- Monte Carlo light transport
- dose-response
- thermal/safety
- EEG/fMRI behavioral endpoints

## Phase 5：发展、个体差异与精神健康

围绕 Cui Lab 文献体系：

- personalized functional topography
- association cortex variability
- youth brain development
- executive function
- psychopathology / p-factor
- structural-functional coupling
- normative modeling
- sensorimotor-association axis
- ADHD developmental deviations
- treatment response prediction

## Phase 6：多模态与独立研究能力

- EEG-fMRI / TMS-EEG / TMS-fMRI
- dMRI + fMRI + iEEG
- structure-function coupling
- multimodal predictive models
- preregistration
- reproducible pipelines
- external validation

### 终极掌握标准

对任何分析都能回答：

> 为什么用这个方法？如果换一个方法，科学问题会变成什么？它依赖哪些假设？结果能够支持什么、不能支持什么？
