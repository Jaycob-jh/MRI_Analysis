# 知识地图

## A. 基础层

### 神经科学
- 神经解剖
- 神经生理
- 神经递质与兴奋/抑制
- 皮层层级、白质通路、功能系统
- 发育神经科学

### 数学与统计
- 线性代数：向量、矩阵、特征值/SVD
- 概率：随机变量、分布、条件概率
- 统计推断：估计、SE、CI、假设检验
- 回归与 GLM
- 重复测量与混合模型
- 多重比较
- 置换与 bootstrap
- Bayesian
- 预测与交叉验证

### 信号处理
- 采样与 Nyquist
- aliasing
- FIR/IIR
- phase / zero-phase filtering
- Fourier / STFT / wavelet
- convolution
- power spectrum
- coherence
- 自相关与平稳性
- SNR 与可靠性

## B. 测量模态层

- MRI：T1/T2、BOLD、diffusion
- EEG：电位差与头皮体积传导
- MEG：神经电流产生的磁场
- iEEG/sEEG：颅内局部场电位
- TMS：时变磁场诱导电场
- tES：外加电流导致脑内弱电场
- tPBM：近红外光传播与光生物调节

## C. 表征层

- voxel / vertex
- ROI / parcel
- tract / fixel
- sensor / source
- time series
- spectrum / time-frequency map
- connectivity matrix
- graph/network
- latent component
- individualized network topography

## D. 建模层

- GLM / generalized GLM
- LME / GLMM / GEE
- GAM / GAMM
- normative modeling
- PCA / ICA / CCA / PLS
- network models
- machine learning
- causal / mediation / moderation

## E. 推断层

- t / F / χ² / Wald / LRT
- effect size / CI
- FWE / FDR
- permutation / max-T / TFCE
- NBS / TFNBS
- spatial null models
- bootstrap stability
- nested CV / external validation

## F. 科学问题层

- 脑网络如何组织？
- 结构如何约束功能？
- 青少年时期怎样发育？
- 个体之间为何不同？
- 个体化功能网络是否与认知/精神症状相关？
- ADHD 等精神障碍是否表现为偏离正常发育轨迹？
- 脑刺激能否改变网络或行为？
- 能否预测未见个体的认知、症状或治疗反应？
- MRI、EEG/MEG、iEEG 与刺激结果如何互相验证？

---

核心路线：**测量 → 表征 → 建模 → 推断 → 验证 → 科学解释**。
