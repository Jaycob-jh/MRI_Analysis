## Source policy

- 自己制作、明确有许可的材料：可直接归档。
- 公开论文：优先保存 DOI/URL + 自己的结构化笔记，不复制受版权保护的全文。
- 实验室内部资料：使用 private repository。
- 每条关键方法笔记记录“来源 + 日期 + 软件版本/论文版本”。
