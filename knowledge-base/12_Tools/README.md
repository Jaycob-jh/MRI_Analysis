## 每个软件条目必须记录

```
算法/模型是什么
输入格式是什么
关键参数是什么
默认值是什么
输出是什么
QC 怎么做
版本是什么
随机性/seed 怎么处理
如何复现
```

禁止用“软件跑出来了”替代方法解释。
