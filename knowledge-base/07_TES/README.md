# 07 tES

## 物理链条
```
electrode current
→ scalp/skull/CSF current flow
→ intracranial electric field
→ orientation-dependent membrane polarization
→ network / behavioral effect
```

## 类型
- tDCS
- tACS
- tRNS

## 关键剂量变量
- current amplitude
- electrode area
- current density（注意只是电极层面的简化量）
- montage
- duration
- ramp
- impedance
- frequency / phase（tACS）
- waveform

## E-field modeling
- MRI-derived head model
- tissue segmentation
- conductivity
- finite element model
- cortical E-field magnitude / normal component
- group vs individualized montage

## 设计
- sham
- blinding
- sensation
- repeated sessions
- dose-response
- target engagement
- behavior / EEG / fMRI endpoints

## 统计
- active × time interaction
- crossover model
