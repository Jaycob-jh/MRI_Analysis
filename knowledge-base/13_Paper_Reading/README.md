# 13 Paper Reading

目标：把论文变成可复用知识，而不是“读完一篇忘一篇”。

## 每篇论文的固定产物

1. Citation + DOI/全文链接
2. 一句话核心贡献
3. Research gap
4. Study design / sample / modality
5. Independent unit
6. Data → analysis → result 流程
7. Primary analysis
8. Robustness / control analysis
9. 关键结果
10. Statistical inference
11. 限制与可泛化性
12. 对自己研究的迁移
13. 三条必须记住的知识
14. 四道理解题

## 理解题层级

- Q1 核心问题：作者究竟解决了什么？
- Q2 方法：为什么选择这个模型/算法？
- Q3 证据：结果真正支持什么，不能支持什么？
- Q4 迁移：如果用于自己的研究，哪些设计必须改变？
