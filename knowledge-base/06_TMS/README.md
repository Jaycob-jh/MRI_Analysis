# 06 TMS

## 物理链条
```
coil current
→ time-varying magnetic field
→ induced electric field
→ membrane polarization / neural response
```

## 基础概念
- coil geometry
- intensity
- orientation
- hotspot
- neuronavigation
- scalp-cortex distance
- electric-field modeling

## Motor Physiology
- MEP
- resting motor threshold (RMT)
- active motor threshold (AMT)
- input-output curve
- cortical silent period

## Paired-pulse
- SICI
- ICF
- LICI 等

## Repetitive protocols
- rTMS
- iTBS
- cTBS
- dose / pulse number / train / interval

## TMS-EEG
- TMS-evoked potentials
- amplifier saturation
- auditory/somatosensory confounds
- artifact removal
- source/network analysis

## 研究设计
- active vs sham
- within-subject crossover
- baseline/follow-up
- responder definition
- blinding
- repeated-measures statistics

## 必须避免
- 把“某 protocol 名称”当成固定生理效应。
- 把 group 内 pre/post 显著而 sham 不显著，误写成两组差异显著。
- 忽略 E-field、coil placement 与个体解剖差异。
