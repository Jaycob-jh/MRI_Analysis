# 08 Transcranial Light Stimulation / tPBM

## 基础术语

- wavelength (nm)
- optical power (W)
- irradiance (W/cm²)
- exposure time (s)
- fluence / radiant exposure (J/cm²)
- spot size
- CW vs pulsed
- pulse frequency
- duty cycle

最基本关系：
```
fluence = irradiance × time
```

但设备表面剂量 ≠ 脑内实际光剂量。

## Tissue Optics
- absorption coefficient
- scattering coefficient
- reduced scattering coefficient
- anisotropy
- refractive index
- scalp/skull/CSF attenuation
- penetration depth

## Modeling
- Monte Carlo photon transport
- individualized head anatomy
- wavelength-specific optical properties
- spatial dose distribution

## Mechanism（作为待验证机制，不应过度简化）
常见研究讨论线粒体/细胞色素氧化酶、血流、代谢和神经调节等路径。学习时必须区分：
- 已直接测量的生理变化
- 间接证据
- 假设机制

## 实验设计
- wavelength
- irradiance / fluence
- target site
- continuous vs pulsed
- thermal monitoring
- sham
- blinding
- EEG/fMRI/fNIRS/behavior outcomes
